1

创建 GitHub Personal Access Token

点击下方按钮，在 GitHub 网站创建一个新的 Token：

前往 GitHub 创建 Token
操作步骤：
1. 点击上方按钮，登录 GitHub（如未登录）
2. 页面会自动填写描述和勾选权限
3. 滚动到最底部，点击绿色按钮 "Generate token"
4. 复制生成的 Token（以 ghp_ 开头）
2

粘贴并验证 Token

将刚才复制的 Token 粘贴到下方输入框：

3

保存并启用自动同步

验证成功后，点击下方按钮保存 Token 并启用自动同步：

配置完成后，工作台将在每次编辑后自动上传数据到云端，打开页面时自动检查更新
